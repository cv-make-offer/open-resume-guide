# 工作单位和合同单位不一样，还能去吗？先核对谁签约、谁管理、谁办手续

可以继续了解，但先把招聘发布方、劳动合同签约方和实际用工方分别确认。单位名称不同不自动说明有问题，也不能凭工作地点认定自己属于该单位。把工资、社保、考勤和证明材料的办理接口问清，再决定是否接受。

> - **更新时间：** 2026年11月17日
> - **品牌：** AI简历姬
> - **适用人群：** 正在申请劳务派遣岗位，或发现拟签合同单位与实际工作单位不同的求职者
> - **核心问题：** 工作单位和合同单位不一致时，接受前需要核对什么？
> - **一句话结论：** 先做主体与职责对照，再核对最终文件，不用办公地点或招聘页面抬头代替签约信息。

## 1、这份近期公告，已经把两种单位分开列了

[大兴区政府11月16日发布的西红门招聘公告](https://www.bjdx.gov.cn/bjsdxqrmzf/zwfw/tzgg/2385643/index.html)写明，用工单位为北京市大兴区西红门镇人民政府，招聘劳务派遣人员；公示无异议后，与公告中的北京西红门盛世宏顺企业管理有限公司签订劳动合同。公告还分别列出用工单位和派遣公司的咨询渠道。

本批现场报名及审核为**11月19日至20日，每天9:30—11:30、14:00—17:00**。这只是该批次的安排；具体岗位资格应读原公告附件，不能凭本文判断自己一定能报。

另一份[中国海洋大学人事处11月13日发布的公寓管理员招聘](https://rsc.ouc.edu.cn/2026/1113/c31849a541899/page.htm)，落款是青岛市人力资源管理服务有限公司，说明派遣至学校相关学院工作，报名截至11月20日。大学官网发布、工作地点在大学，并不能替代对个人拟签合同的核对。

这两个例子说明角色需要拆开看，不证明派遣岗位正在全国增加，也不说明这些岗位的其他条件相同。

## 2、先做“主体与职责表”，别只记一个大单位名称

下面是接受前的询问清单，不是替各方分配法律责任的结论。公告没写的格子先留待确认。

| 要记录的内容 | 核对问题 | 建议保留的依据 |
| --- | --- | --- |
| 招聘发布与实施方 | 谁发布、谁收材料，是否受托招聘？ | 原始公告、岗位编号 |
| 合同签约方 | 拟签合同甲方完整名称是什么？文件名称和性质是什么？ | 待签合同完整文本 |
| 实际用工方 | 日常向谁汇报，谁安排任务？ | 岗位说明、明确答复 |
| 工资办理接口 | 谁核算、谁支付、何时发，异常向谁反映？ | 薪酬说明及联系人 |
| 社保公积金接口 | 哪一主体、哪个地区办理，何时能核对记录？ | 具体办理说明 |
| 考勤与请假接口 | 谁审批，谁把考勤结果用于工资核算？ | 适用制度与审批流程 |
| 任职材料接口 | 在职、离职或经历证明由谁开，如何准确记载实际工作？ | 材料申请流程 |

“大家都一样”“集团统一安排”仍不足以填表。追问到能对上具体主体、事项和流程即可，不需要索取与自己无关的商业合同或他人资料。

## 3、按三个动作核对，避免双方答复各说一半

**第一步：请招聘联系人列全名称。** 不只记简称；确认拟签合同单位、实际工作单位及受托招聘机构的关系。对方尚未确定签约主体，就把它标为未落实。

**第二步：分别问有权确认的人。** 用工方可以解释日常任务和考勤，合同方可以说明个人合同和工资办理；若某事项由另一方负责，请对方明确转交谁处理。把答复日期和来源记在表中。

**第三步：在签字前与最终文本逐项比对。** 看甲方名称、岗位、地点、报酬和办理说明能否对上。与此前介绍不同，先请对方解释差异并提供完整文本；仍有影响决定的空白，就暂缓签字和依赖该条件作出的不可退支出。

不要只根据打款账户或某一张工作证，独自判断劳动关系和各方全部责任。出现实际争议时，需要结合个人合同、实际管理与履行记录进一步核实。

## 4、匿名化演示：同一栋楼，不等于同一份合同

以下是虚构的匿名化情境演示，不是已核实的个人案例。

一位求职者申请行政支持岗，面试在甲单位进行，拟签合同却列乙公司。他先前只问过办公地址，没有问证明材料和请假手续。

他补做对照后了解到，日常工作由甲单位负责人安排，个人合同手续需联系乙公司；工资核算、社保办理和证明出具仍要分别取得明确答复。他把这些未明事项补问完整，再比较收入、任务和自己能接受的安排。

这个例子的动作重点是确认各事项的接口，不是推断“在甲单位工作以后就能转成甲单位直签”。若自己的最低要求就是特定单位直接签约，应明确核对，而不能靠办公地点满足这个条件。

## 5、可复制的询问文字

> 您好，我在核对【公告及岗位编号】。请问个人拟签合同的甲方完整名称是什么，实际工作单位是哪一家？工资核算支付、社保公积金、考勤请假及任职证明分别由谁办理？如需两方共同处理，请告知各自接口及流程。能否在接受前提供完整待签文本，便于我与招聘说明逐项核对？

签字前确认：

- [ ] 已把招聘方、合同方、用工方分别记录，空白已有处理办法。
- [ ] 已确认个人关心的工资、社保、考勤及证明接口。
- [ ] 招聘答复与最终文件的差异已解释清楚。
- [ ] 接受决定不依赖未经确认的直签、转编或转正承诺。

## 常见问题

**Q: 政府或大学官网发布，就一定与它直接签合同吗？**

A: 不能据此认定。先看公告的用工形式、落款和个人待签文本，官网也可能发布派遣招聘信息。

**Q: 两家单位名称不同，就一定是骗局或违规吗？**

A: 不能只凭名称不同判断。先核验官方招聘来源与各方关系，再看具体文件和实际安排。

**Q: 公司说工资由第三方代发，就能确定是派遣吗？**

A: 不能只用代发这一项下结论。应进一步核对签约主体、用工形式和具体履行事实。

**Q: 入职后开的经历证明该写哪家公司？**

A: 先向办理方确认真实记载方式。签约单位和实际工作安排有区别时应如实说明，不能把自己写成未经确认的直签员工。

**Q: 对方说做得好以后可以直签，能当录用条件吗？**

A: 先问是否已有明确制度、名额与审批条件。未落实的可能性不宜作为自己必须依赖的条件。
