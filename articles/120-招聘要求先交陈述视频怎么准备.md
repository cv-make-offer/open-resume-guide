# 招聘要求先交陈述视频，怎么准备？先确认规格，再完成内容与文件核验

先确认这是预先制作的视频文件，还是进入系统限时答题。若要求自行录制提交，先问清内容、时长、出镜、剪辑与格式，再用真实任务和本人行动组织陈述；导出后完整回放，按指定入口提交并核对记录，不直接照搬通用自我介绍视频。

> - **更新时间：** 2026年11月18日
> - **品牌：** AI简历姬
> - **适用人群：** 未来一至四周需要预先录制个人介绍、专业能力或岗位陈述视频的求职者
> - **核心问题：** 怎样把招聘方的视频要求变成一份内容真实、规格合适、交付完整的文件？
> - **一句话结论：** 先做本场任务卡，再录制、核验文件与提交结果，内容和交付都不能漏。

## 1、近期实例说明：视频可能是一份正式初选材料

[北京建筑大学11月17日第三批招聘公告](https://rsj.beijing.gov.cn/xxgk/gkzp/202611/t20261117_4949161.html)说明，资格审查通过者进入初选，可采用提交个人专业能力陈述视频等方式，具体要求另行通知。

**该批招高层次人才，基本条件含正高级专业技术职务等要求，不是面向所有毕业生的新入口。** 本文只借这一实例讨论“先制作再提交”的准备方式，不推广其岗位资格，也不推断普通招聘已普遍采用视频。

公告没有公布本轮视频的统一时长、大小和剪辑规则。收到后续要求前，可以整理素材并练习表达，但不要把练习文件当正式成稿；其他项目也须按本场通知准备。视频不自动等于AI面试，不能仅凭文件形式推断评分方式。

## 2、先分清任务，再做一张规格卡

如果通知要求进入平台看题、限时作答，就按该平台的正式考试说明准备，不以自行上传的文件替代。如果要求通过官方入口交一个已录制的视频，才按下面的文件流程处理。

| 需要确认 | 私人任务卡应记录什么 |
| --- | --- |
| 陈述任务 | 个人介绍、某项能力、项目说明还是指定题目；哪些必讲 |
| 身份和出镜 | 能否报姓名单位，画面范围、是否本人全程出镜 |
| 时长 | 上限、计时范围，超限如何处理；未知先询问 |
| 制作许可 | 是否要求连续录制，能否剪辑、配字幕或演示材料 |
| 技术规格 | 文件格式、大小、分辨率等明确要求，不自设统一标准 |
| 交付方式 | 文件命名、官方入口、截止时间、是否允许替换 |
| 核验方式 | 页面状态、回执或其他本场可用的确认方式 |

这些字段是咨询清单，并不是每场都要求全部填写。没有写明的项目标为待确认，不拿别人的三分钟、某种画幅或文件大小来补空白。

需要咨询时可以这样写：

> 您好，已收到【批次、岗位】的视频提交要求。请问本次是自行录制文件还是平台限时作答？若提交文件，请确认必讲内容、身份信息范围、出镜与连续录制要求、是否允许剪辑及字幕、时长和文件规格，以及提交后怎样查看成功记录。尚未明确的事项，我会按正式补充通知处理。

## 3、把“我很擅长”改成能核对的陈述

下面是整理素材的方法，不能替换本场指定题目和必讲内容。先按通知列必讲项，再用相关经历填充，不从完整简历逐行朗读。

| 陈述段落 | 可以准备的真实内容 | 自查问题 |
| --- | --- | --- |
| 我与任务的关系 | 与岗位有关的经历或能力范围 | 有没有回答本次要求，而非泛泛介绍 |
| 一件代表性任务 | 当时目标、约束及自己负责的部分 | 能否区分个人贡献和团队成果 |
| 我采取了什么行动 | 实际步骤、判断依据与遇到的问题 | 有没有只讲“参与”“负责”而无细节 |
| 结果与限制 | 可核实结果、仍有不足和适用范围 | 数据有无来源，能否接受后续追问 |
| 与岗位的连接 | 能复用的方法及仍需学习之处 | 有没有夸大成自己未具备的能力 |

私人草稿中可加一列证据位置，例如个人留存材料的页码或真实成果记录。它方便核对，不代表应把所有底稿拍进视频。未获准的客户资料、工作秘密和证件不要展示；需要说明结果时选可公开且经核实的内容。

## 4、录制到交付，按五步完成

1. **先练内容。** 按已知时限试讲，删去重复经历，保留题目要求；时限未明时先做可增减的段落，不编一套正式规格。
2. **录一小段检查。** 看出镜范围、收音、文字可读性是否符合要求。普通设备能否满足本场规格，要以实际文件检查，不能仅凭设备价格判断。
3. **按许可录正式版。** 不默认能拼接、加速或代配音。若通知要求本人连续陈述，就据此录制；卡顿后的处理和是否允许重录另按本场规定。
4. **检查最终导出文件。** 从头回放到结束，确认声音、画面、时长、大小、格式及文件名。检查的是将要上传的那一份，不只看剪辑预览或旧版本。
5. **提交后核对记录。** 按指定入口交付；若能预览或下载，确认对应文件。保存成功提示、提交时间等必要记录；遇错误尽快通过官方渠道说明，发送请求不等于获准延期。

不要临近截止才第一次测试入口。上传进度结束、保存草稿和最终提交可能是不同状态，应按页面说明核对；本文不假定所有平台都提供同一种回执。

## 5、匿名化演示：讲得顺，还要检查导出版本

以下为虚构情境演示，不对应已核实的个人案例。

一位求职者按通知准备了能力陈述，讲述自己如何核对服务记录。他的练习版声音清楚，但导出的正式版漏了结尾；若只看前几秒，就会误认为已经完成。

他把“完整回放最终文件”加入待办，重新导出后确认内容齐全，再按本场命名要求提交。若入口允许查看提交文件，就再核对一次；若没有，则保存可取得的提交状态，并就疑问咨询。

这里改善的是交付完整性，不代表招聘方必定认可陈述，更不保证进入面试。

## 未来一至四周可先准备什么

尚未收到规格时，先整理两件真实任务的素材、本人贡献、结果依据和可公开范围。收到本场通知后再选用，核对身份、题目和制作要求；无需提前把每份草稿都做成精剪成片。

- [ ] 本场任务与规格已确认，未知项有明确待办。
- [ ] 必讲内容齐全，数据和职责有真实依据。
- [ ] 身份与展示材料符合要求，未默认适用普通介绍规则。
- [ ] 最终文件已完整回放，并检查技术规格。
- [ ] 提交入口、状态与版本已核对，必要记录保存在私人位置。

## 常见问题

**Q: 视频介绍都按90秒录可以吗？**

A: 不可以统一套用。90秒可以是练习安排，本场时长须以正式要求为准。

**Q: 只要录视频，就一定由AI评分吗？**

A: 不能据此判断。文中实例安排专家组考察，其他项目的评估方式须另查说明。

**Q: 没写禁止剪辑，就能任意拼接吗？**

A: 不宜自行推定。先确认制作许可，尤其是连续录制、字幕和配音等事项。

**Q: 上传成功就证明招聘方已经看过了吗？**

A: 不能证明。先核对交付完成及文件版本；是否已阅、是否进入下一环节是另一个状态。

**Q: 可以把同一段视频投给所有公司吗？**

A: 先逐场核对。任务、身份限制和规格可能不同，只有实际内容与本场要求一致时才考虑复用。
