# 面试后要求先交培训费，还是在招人吗？先查岗位、收费和借款三件事

先暂停付款和借款。招聘面试转成卖课后，不能再把培训协议当作录用通知；“入职后再付”也可能包含借款义务。核对谁实际招人、谁提供课程、谁收钱或放款，以及不参加付费培训能否继续应聘，再决定是否退出并保留证据。

> - **更新时间：** 2026年11月4日
> - **品牌：** AI简历姬
> - **适用人群：** 被零经验岗位吸引、面试后被要求购买培训或办理分期的应届生与转行者
> - **核心问题：** 招聘流程变成收费培训后，应怎样判断并处理？
> - **一句话结论：** 将招聘、培训和借款分别核验，拒绝把付费培训当成获得岗位的保证；不清楚债务与费用前不签、不付。

## 1、这是已有风险，近期检查仍将其列为重点

[湖北省人社厅10月23日检查结果公示](https://rst.hubei.gov.cn/bmdt/dtyw/tzgg/202610/t20261023_6038728.shtml)将整治“招转培（贷）”欺诈列为专项行动重点之一。11月4日复核，该正文能说明监管关注的事项，不能据此推算全国发生率，也不能认定某家机构违法；本文未逐项审查其检查附件。

更具体的识别依据是[中国就业网5月18日刊载的五部门风险提示](https://chinajob.mohrss.gov.cn/h5/c/2026-05-18/543038.shtml)：其中指出，有人通过招聘吸引求职者，面试时强调能力不足，再转向高额培训或贷款；招聘、培训主体可能分离，“成功入职再收费”等说法也可能用来诱导签约。

这份提示不是11月新发布的政策，本文也没有证据声称骗局本周增加。这里解决的是眼前的一次决定：**你原本在申请工作，现在被要求承担的究竟是什么？**

## 2、把三个主体和三份责任对齐

| 事项 | 要确认的内容 | 常见误读 |
| --- | --- | --- |
| 招聘 | 实际用人单位、具体岗位、是否仍在招聘、谁决定录用 | 培训销售说与大厂合作，就等于大厂已录用 |
| 培训 | 合同主体、课程交付、总费用、收款方、退出条件 | 签了课程合同，就有了工作保障 |
| 借款 | 是否形成借贷、放款方、还款对象与日期、相关责任 | 现在不掏现金，就没有债务 |

不同公司参与不自动证明欺诈，但不能因此省略核验。用原招聘渠道或自行查到的企业官方渠道确认岗位，不只联系销售指定的“HR”；如果对方声称代表另一家公司，要求说明可核实的招聘授权。

询问一句关键问题：**“如果我不购买这项培训，是否仍能按原岗位条件应聘？”** 如果回答变成“交钱才安排”“学完推荐但不保证录用”，就应将它与原招聘机会分开判断。五部门提示明确建议，对求职中被要求先参加高额付费培训才安排岗位的情况果断拒绝。

## 3、不要被“先学后付”跳过合同核验

“不收费”“分期”“从未来工资扣”都需要看具体文本。先取得拟签协议，按下面四项查，不在现场催促下连续点击确认：

1. **钱是什么。** 培训费、服务费还是借款？总额和支付对象能否对应，是否还有另行协议？
2. **何时需要付。** 没被录用、课程结束、收入不足或中途退出时，文本怎样约定？口头承诺有没有写入？
3. **谁承担责任。** 承诺退费的人是不是合同责任方；培训退出与借款处理是否分别说明？
4. **岗位承诺是什么。** 提供课程、推荐面试和由用人单位录用，是不同交付。不要把推荐当保证。

这些是核验问题，不是对某份合同效力的法律结论。对方不愿提供完整协议、说“先开通额度再解释”，就停止操作。也不要把验证码、账户密码交给对方代办。

主动购买学习服务是另一种决定：即使没有这份岗位，你是否仍然需要该课程、能承受费用、认可交付？若答案是否定的，就不应为了一个未经核实的录用承诺负债。

## 4、根据已经走到哪一步处理

| 当前情况 | 先做什么 |
| --- | --- |
| 尚未签约付款 | 暂停交易，核验岗位与主体，索取完整文本 |
| 已签培训协议，尚不清楚是否借款 | 保存签署文本，向协议载明的相关机构核对真实状态，别只听销售解释 |
| 已付款或已有借款记录 | 保存协议、凭证、沟通与平台记录，分别确认培训及借款处理渠道 |
| 怀疑被虚假招聘引流或诱骗 | 向招聘平台反映，并按情况向人社部门投诉举报或向公安机关报案 |

不要相信“再交一笔钱才能退费”的口头要求，也不要把聊天中一句“已取消”当作所有合同和借款都已处理。已有借款时，不能自行认定退课等于债务消失；具体如何处理，应向相关机构核实，必要时寻求专业帮助。本文不承诺退费结果，也不建议凭销售说法自行停止应履行的还款安排。

## 5、匿名化演示与拒付模板

以下是匿名化情境演示，不对应真实个人或特定机构。

一位转行者申请运营助理，面试后被告知先学课程，费用“找到工作再付”。他索取文本后，发现一份是培训服务协议，另有分期相关文件；对方给出的交付是推荐面试，没有用人单位的录用通知。

他先暂停签署，向原招聘渠道核实是否存在该岗位，保存招聘广告及费用说明。判断变化在于：他不再把“课程销售愿意接收”理解成“雇主愿意录用”，也没有仅凭主体不同就公开指控诈骗。

可以这样表达：

> 我申请的是【岗位】，目前收到的是培训及费用安排。请先提供实际用人单位、可核实的招聘渠道，以及培训合同、全部收费和是否涉及借款的完整说明。在确认前，我不办理付款、分期或贷款。如不购买课程就不能继续应聘，请明确告知，我将据此决定是否退出招聘流程。

最后核对：

- [ ] 招聘、培训、收款或放款主体分别记录，没有只记一个品牌名。
- [ ] 清楚签的是哪种协议，没有把推荐就业当录用。
- [ ] 不把“现在不付”理解为没有将来付款或借款义务。
- [ ] 如已有争议，保存原始证据，通过正式渠道处理，不公开个人敏感资料。

## 常见问题

**Q: 只要有培训就是骗局？**

A: 不能一概认定。重点是招聘是否真实、费用与借款是否透明，以及是否用付费培训替代原录用承诺。

**Q: 说入职后才扣钱，就不用担心贷款吗？**

A: 不能这样判断。看实际协议与账户记录，确认是否存在借贷及还款责任。

**Q: 培训公司和招聘公司不同，就一定违法？**

A: 不能仅凭这一点定性。应核验岗位、授权与各方责任，遇到不明费用先暂停。

**Q: 对方承诺包就业，值得贷款赌一次吗？**

A: 不要据此借款。先核实岗位和合同交付，口头保证不能替代用人单位的真实录用决定。

**Q: 已经退课，借款也自动取消了吗？**

A: 不要默认。分别向培训和借款相关机构确认处理结果，保留正式记录。
