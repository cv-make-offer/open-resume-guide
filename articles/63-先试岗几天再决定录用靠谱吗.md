# “先试岗几天再决定录不录用”靠谱吗？求职者应该确认什么？

先别只看试岗几天，要看是否已经实际工作。模拟考核应说明范围和反馈；如果按公司安排排班、接单、交付真实业务，就要确认用工、工资和合同，不能接受“没录用所以白干”。说不清这些安排时，先暂停到岗。

> - **更新时间：** 2026年10月19日
> - **品牌：** AI简历姬
> - **适用人群：** 收到短期试岗、到店试工或先上班后决定录用的要求，不确定是否应接受的人
> - **核心问题：** 先试岗再录用该不该去，开始前需要确认哪些条件？
> - **一句话结论：** 先分清考核与实际用工，再把工作内容、报酬、合同和结束安排确认清楚，不用免费工作换取不确定的录用机会。

面试快结束时，对方说：“下周先来三天，我们看看你合不合适，合适再办入职。”你想争取机会，又担心做完被告知“不适合”，连工资也没有。

“来看看工作环境”“做一次模拟操作”和“连续几天顶岗工作”，涉及的安排并不一样。本文面向中国大陆一般企业求职场景；在校教学实习、独立项目合作等情形，需要结合实际关系另行判断。

## 1、先问：这几天究竟要做什么

不要只问“试岗有工资吗”，先让对方把每天的活动说具体。下面是初步核对表，不能代替对劳动关系的事实认定。

| 对方安排 | 应当追问什么 | 下一步怎么做 |
| --- | --- | --- |
| 参观、介绍岗位、观察工作流程 | 是否需要承担任务，预计多久？ | 确认仅为了解岗位，再安排时间 |
| 用模拟材料做一次操作测试 | 考什么、交什么、谁评估、何时结束？ | 把范围和反馈时间写清楚 |
| 按门店排班接待顾客、完成订单 | 谁管理、工资怎么算、从哪天算用工？ | 按实际工作要求确认用工安排 |
| 加入团队连续处理真实业务 | 是否办理入职、何时签合同、试用期如何约定？ | 条件明确后再决定到岗 |
| 先干几天，只有留下才给钱 | 为什么实际工作报酬要取决于录用？ | 先暂停，要求调整安排 |

例如，“模拟接待一位顾客并解释处理思路”与“周末到店顶班，接待真实顾客并完成交接”就值得分别询问。持续几天只是一个线索，具体是否属于用工，还要结合管理、任务和实际履行等情况判断，不能靠改称“体验”就解决。

上海人社在2026年4月30日的便民问答中，明确否定了入职后设置七天无薪“试岗期”的做法：已经存在用工行为，应依法支付劳动报酬，考察工作能力可以依法约定试用期。[查看上海人社官方答复](https://rsj.sh.gov.cn/dzb/rsj/2026-04-30/aid/04-03.html)。这不能反推所有参观、面试测试都属于劳动关系，但足以提醒你：实际工作不能只由“是否最终留下”决定有没有报酬。

## 2、准备到岗前，把这六件事落实

口头说“放心，肯定不会亏待你”不够安排自己的时间。至少要拿到可以保存、可以核对的明确回复。

1. **为谁工作：** 实际用工主体是谁，招聘沟通方与签约、支付报酬的主体是否一致？有第三方参与时，分别承担什么职责？
2. **做什么工作：** 地点、日期、每天时段、负责人、任务范围是什么，是否接触设备、客户或真实业务？
3. **怎么算报酬：** 标准、计算方式和支付日期是什么？即使后续未录用，已工作部分如何结算？
4. **怎么办理合同：** 从哪天开始用工，书面劳动合同何时签，约定的试用期是否包含这几天？
5. **按什么考核：** 要达到哪些具体要求，谁评估，什么时候告知结果，有没有说明或反馈机会？
6. **如何结束：** 双方决定不再继续时，怎么办理通知、交接和结算？不要把“试岗结束”自动理解成可以随意解除。

可以直接发这段话：

> 您好，我愿意进一步了解岗位。想先确认这次是招聘中的模拟考核，还是开始实际工作。若需要按安排处理真实业务，请明确用工主体、起始日期、工作时段、报酬标准及支付日期、劳动合同和试用期安排；也请说明考核要求，以及未继续录用时已工作部分的结算和交接方式。确认后我再安排到岗。

若只是模拟考核，可以另问任务范围、预计投入、材料用途和反馈节点，不用把所有正式入职材料提前交过去。对方后来临时改成真实业务，要重新确认安排。

## 3、“试岗”和试用期，不能在合同里含混过去

《劳动合同法》第七、十条规定，劳动关系从用工之日起建立，建立劳动关系应订立书面劳动合同；未同时订立的，应自用工之日起一个月内订立。第十九条规定，试用期包含在劳动合同期限内，同一单位与同一劳动者只能约定一次试用期。[查看怀化市人社局公开的法律文本](https://www.huaihua.gov.cn/rsj/c116048/201507/37d5be05017e4b05ab2d78b6ba367872.shtml)。

据此，沟通中应特别核对两点：

- **“一个月内签合同”不等于前面可以无薪工作。** 可以争取在开始前把合同与工资说清楚；已经用工，也不能只凭尚未签合同就否认工作事实。
- **“先试岗，再从零开始算试用期”需要核对。** 若前几天已经实际用工，合同起始时间、试用期起止和工资记录应一起确认，不要接受事后随意改写日期。

试用期也不是工资可以随便定的理由。《劳动合同法实施条例》第十五条对试用期工资下限有规定，并要求不低于用人单位所在地最低工资标准。[查看国家税务总局法规库中的条例原文](https://fgk.chinatax.gov.cn/zcfgk/c100010/c5194419/content.html)。实际标准应结合合同、岗位工资和当地适用规定核对，不要只接受一个没有依据的“试岗日薪”。

关于结束安排，《劳动合同法》第二十一、三十九条涉及试用期解除及被证明不符合录用条件等规定。试用期内也不能仅凭一句“感觉不合适”就认定单位可任意解除。[查看对应条文](https://www.huaihua.gov.cn/rsj/c116048/201507/37d5be05017e4b05ab2d78b6ba367872.shtml)。这也是为什么开始前要问清录用条件和考核要求。

## 4、对方不愿说清楚，可以怎样协商

如果主要目的是看操作能力，可以提出一个范围明确的模拟考核；如果确实需要连续几天参加真实工作，就请求落实实际用工安排。不要只把“不付钱”改成“给一点补贴”，其他条件继续空着。

| 招聘方的回复 | 可以这样回应 |
| --- | --- |
| “大家都要先免费做几天” | “如果是实际工作，希望先确认报酬与合同安排；如果是考核，能否改为有明确范围的模拟测试？” |
| “留下来才一起算工资” | “后续是否继续与已经完成的工作需要分开确认，请明确未继续时的结算方式。” |
| “先来，来了再谈” | “我需要据此安排时间，请先以文字确认任务、报酬和办理方式，再确定到岗。” |
| “岗位值得来，没必要问这么细” | “这些条件会直接影响我能否参加，确认清楚也能减少双方后续分歧。” |

对方始终不解释，或者要求先支付试岗押金、培训保证金，先停止付款和到岗安排。《劳动合同法》第九条禁止招聘时扣押身份证等证件、要求担保或以其他名义收取财物。[查看人社部门公开的法律原文](https://www.huaihua.gov.cn/rsj/c116048/201507/37d5be05017e4b05ab2d78b6ba367872.shtml)。交验与扣留原件要分清，别把证件长期留给对方。

## 5、一个门店试工的沟通示例

以下为匿名化情境演示，不对应已核实的个人案例。

一位求职者应聘门店运营，对方要求连续三天跟班。他询问后得知，需要按门店时间到岗，接待顾客、处理订单并做闭店交接，但招聘方说“不留下就没有工资”。

这时不必先争论对方是不是故意骗工。求职者可以提出：如果只想观察接待能力，改用模拟顾客情境，当场操作并讲解；如果需要承担三天真实工作，就先明确用工日期、报酬、合同与考核安排。

如果招聘方仍坚持无薪完成真实业务，求职者可以停止这次安排。若双方改为明确的实际用工，也要核对最终文件是否与沟通一致，不能只靠一次口头答应。

已经做了几天才被拒绝时，先保存招聘信息、任务分配、出勤、工作交接、报酬约定和沟通记录。只留存自己有权获取的必要材料，不带走客户资料或内部业务数据；可带着事实记录向当地人社部门咨询，具体劳动关系和款项争议需结合证据处理。

## 常见问题

**Q: 只试岗一天，公司也得给工资吗？**

A: 要看是否已经实际用工，不能只用天数判断。属于实际工作的，不能因只做一天或最终未录用就当然免付报酬；单次模拟面试测试则需要按实际安排区分。

**Q: 我签了“自愿无薪试岗”，就没办法了吗？**

A: 不能仅凭这份文件下结论。名称和签字不能代替对实际用工、报酬及条款效力的判断；保留文件与工作记录，就具体情况向当地人社部门咨询，不要自行认定一定能追回或一定追不回。

**Q: 公司说给交通补贴，这样就能去吗？**

A: 仍要确认做什么及双方是什么安排。交通补贴不能自动替代实际用工应有的工资等安排，也不能只凭有补贴就判断流程妥当。

**Q: 在职期间请假去试岗，有什么需要考虑？**

A: 先区分模拟考核和实际工作，再核对现有劳动合同、规章制度及保密义务。不要把原单位资料带去，也不要为了尚未确认条件的机会仓促辞职。

**Q: 不接受免费试岗，会不会丢掉这个机会？**

A: 可能会影响流程，协商不能保证录用。你可以提出有限模拟测试或条件明确的用工安排，再根据对方回复决定；已经投入面试时间，也不意味着必须接受不清楚的条件。
